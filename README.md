# Student Profile Card

This project is a fun student profile card made with HTML, CSS, and JavaScript.

It shows a student's photo, name, class, contact details, and a short bio.

What it includes:
- A simple design that works on phones and computers.
- A photo area, name, class/grade, email, phone, and address.
- A small bio about the student.
- Easy to change colors, fonts, and text.

How to use:
- Open `index.html` in a browser to see the card.
- Change the HTML text to your own student details.
- Edit `styles.css` to change how it looks.

What you can add:
- Hobbies, favorite subjects, or school interests.
- Social links or clubs you are part of.
- Awards or projects you are proud of.
